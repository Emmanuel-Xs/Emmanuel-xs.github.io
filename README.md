## Local development

This is a static site, no build tools required. Clone the repo and open `index.html` in a browser, or serve it locally:

```bash
git clone https://github.com/Emmanuel-Xs/Emmanuel-Xs.github.io.git
cd Emmanuel-Xs.github.io
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
